# 💻 SYS_NODE://GHOST-SHELL — PORTFÓLIO TERMINAL

Um portfólio interativo retro-futurista inspirado em interfaces cyberpunk, estilo terminal de linha de comando (CLI) e monitorização de sistemas.

---

## 🚀 Funcionalidades

- **Interactive CLI Terminal**: Permite ao utilizador executar comandos interativos no browser.
- **Efeito CRT Scanlines**: Camada visual com linhas de varredura clássicas de monitores antigos.
- **Matrix Rain Canvas**: Animação em tempo real da chuva de código ao estilo Matrix.
- **HUD Panels**: Exibição de informações sobre o perfil, habilidades em barras de progresso e cartões de projetos.
- **Relógio do Sistema**: Mostrador em tempo real no cabeçalho do sistema.
